# Windows 集中验收（阶段 2–7）

用于一次性验收当前实现。所有项目目前均待新 Windows 产物实机验证，本地测试及过去阶段 1 的检查不替代本轮验收。

## 准备

1. 提交并推送当前改动后，手动运行 GitHub Actions 的 **Build Windows**，选择 `all`。下载同一次成功构建的 ZIP 和 NSIS，记录提交号及 `build-info.json`；方法见 [Windows 构建文档](windows-build.md)。
2. 先退出旧测试版本，保留当前用户配置的备份。免安装版和安装版共享系统用户数据目录，同一时间只运行其中一份。
3. 准备两个互不冲突的测试网络和另一台设备；另一台可使用官方 EasyTier 客户端，邀请解析验收需要另一份 ClearTier。全程不需要向开发者发送网络密钥。
4. 安装／升级会中断现有连接，选择可暂停使用的时间。登录启动和休眠测试在自己的测试电脑进行。

## 配置、连接与指标

- [ ] 添加、编辑、删除网络及更换网络／设备图标后，明确退出重开仍保留；最后选择正确，新网络默认不自动连接。
- [ ] 连接时 GUI 为普通权限，仅核心请求 UAC；同时运行两套不同网络，实际网卡名和地址不冲突。
- [ ] 断开、重连其中一个，另一个仍可通信。相同身份的第二套配置不可同时运行。
- [ ] 在线修改参数后稍后应用，原连接保持；立即应用只重连目标网络，失败显示原因、不恢复旧参数，已保存内容保留。
- [ ] 实际设备、虚拟 IP、直连／中转、可用延迟和丢包正确；未知指标不显示假零。
- [ ] 双向传输数据，速率及当前网络本机累计增长；切换查看网络不会串数据，重连只重置目标会话累计。
- [ ] 验证节点名称、地址分配及所需高级参数的实际效果，尤其 P2P、MTU、Magic DNS 和广播中继。详细步骤见 [官方配置兼容](official-toml.md)。

## 官方迁移与邀请

- [ ] 系统文件对话框可导入、预览及导出 TOML；未展示字段保留，导出可供官方客户端使用，暂不支持的字段明确阻止连接。
- [ ] 点击邀请直接复制，另一台 ClearTier 粘贴后填写并手动添加、连接，双方实际通信成功；不复制发送方网卡、IP、P2P 等本机设置。
- [ ] 待应用修改时分享仍为运行参数并提示；未连接时分享已保存参数。
- [ ] 邀请填入后可修改字段及更换邀请；错误邀请不改表单、不阻止手动添加，重复网络可以打开已有或明确另存。

## 托盘、退出与登录启动

- [ ] 第一次关闭显示后台说明；选择后台运行后窗口隐藏，连接及另一设备的数据传输不中断。
- [ ] 托盘显示应用图标，左键与菜单可重新打开窗口；连续关闭／打开不重新连接、不重复执行自动连接队列。
- [ ] 重复启动程序只唤起已有窗口，不出现第二个 GUI 或连接控制权错误。
- [ ] 设置改为关闭时退出，有运行网络时先确认；取消保持连接，确认后 GUI、核心及临时 TUN 全部清理。
- [ ] 托盘／设置的明确退出遵循同一确认与清理规则；无运行网络时可直接退出。
- [ ] 登录启动默认关闭；启用后注销并重新登录，应用进入托盘，仅已启用自动连接的网络尝试连接。
- [ ] 首次自动连接需要权限时出现一次 UAC；取消后停止本次队列，偏好保留。关闭登录启动后再次登录不启动应用。
- [ ] 如使用免安装版启用登录启动，程序位于固定路径；含空格或中文的路径也能启动。

## 异常与长期运行

- [ ] 临时中断服务器／节点连接后恢复网络，核心仍运行，由 EasyTier 重试；客户端不反复创建网卡或重启实例。
- [ ] 待恢复时主动断开，之后不再自动启动；关闭自动恢复后不会重试已失败网络，重新开启不连接已经断开的网络。
- [ ] 在任务管理器通过命令行中的 `--core-host` 识别并只结束核心工作进程，GUI 留存并显示异常；真实 TUN 恢复需要重新授权时提示手动重连，后台不反复弹 UAC。手动重连后两个网络可重新运行，旧网卡清理正常。
- [ ] 在有未应用修改时触发可恢复的实例异常，恢复使用旧运行参数，已保存新参数及待应用标记保留。
- [ ] 可重试失败最多 3 次；连续短暂恢复后又失败不会无限重试，稳定运行 60 秒后预算才重置。配置／资源错误停止重试并给出原因。
- [ ] 睡眠／唤醒、切换本机上网环境后状态重新同步，无密集重连、数据串网络或多余进程。
- [ ] 后台持续运行并实际使用一段时间，日志保持轮换，CPU／内存无持续异常增长。

## 诊断与安装包

- [ ] 设置显示配置、核心和实例摘要，近期错误可读；打开日志目录正确。
- [ ] 导出系统保存对话框正常，取消不提示成功；JSON 含实际版本、状态、错误码，搜索确认不含密钥、服务器、实际 IP、主机名、用户目录、完整配置及邀请原文。
- [ ] NSIS 安装后可以普通用户启动与连接；再次安装／升级保留配置及启动偏好，现有实例正常清理后才替换文件。
- [ ] 正常卸载前说明连接影响并清理 GUI／核心；默认保留配置，登录启动项删除，重新安装后配置仍可读取。
- [ ] 另一次卸载明确勾选删除应用数据，才删除对应配置与本地数据；不删除其他应用共用的驱动服务。

## 记录结果

记录 Windows 版本、产物提交号、ZIP／NSIS 形式、失败步骤及界面错误。必要时附脱敏诊断 JSON 或核心检查报告，不发送原始网络配置、密钥或邀请。

核心基础检查仍可按 [Windows 构建文档](windows-build.md) 运行；其中名为 `Recovery` 的模式验证的是独立进程基础，不能替代本清单中的 GUI 自动恢复策略。
