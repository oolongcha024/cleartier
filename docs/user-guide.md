# 使用指南

ClearTier 连接已经部署好的 EasyTier 网络，内置兼容核心，无需另装官方客户端。当前优先验证 Windows；macOS、Linux 的完整安装、权限与后台支持仍待验收，非 Windows 自动 TUN 提权尚未实现。

## 安装与加入网络

Windows 发布包从 [Releases](https://github.com/oolongcha024/cleartier/releases) 获取，手动测试包从同次成功构建的 Actions Artifacts 获取，方法见[开发指南](development.md#windows-构建)。免安装 ZIP 需完整解压并保留旁边的运行资源；NSIS 使用当前用户安装。直接运行需要 Microsoft Edge WebView2 Runtime，安装包可按需下载。界面最小尺寸为 900×600。

1. 在仪表盘或网络配置页添加网络，填写网络名称、密钥和服务器地址；服务器需自行准备。
2. 保存后手动连接。新网络默认不自动连接；需要 TUN 时 Windows 仅对核心请求 UAC，取消授权会保留配置。
3. 通过顶部选择器查看其他网络。多网络可同时运行，连接、断开和重连只作用于目标网络。

网络名称和密钥按原文保存。本地名称与图标仅影响本机展示；同名同密钥的记录可确认另存，但相同网络身份不能同时运行。删除前先断开，状态未知或资源未释放时不能删除。

## 编辑与应用修改

| 修改                     | 生效方式                             |
| ------------------------ | ------------------------------------ |
| 本地名称、网络或设备图标 | 保存后直接更新，不重连               |
| 在线网络的连接参数       | 可仅保存，或保存后立即重连目标网络   |
| 离线网络的连接参数       | 保存后等待下次手动连接或启动自动连接 |

“待应用”表示已保存参数与实际连接不同。“重连并应用”使用已保存参数，失败时保留修改和实际错误，不恢复旧参数。保存失败保留输入；遇到外部修改冲突时先重新加载，避免覆盖他人修改。

高级选项包含节点名称、IPv4 分配、TUN、MTU、IPv6、P2P、打洞、UPnP、Magic DNS 和 Windows 广播中继。“关闭自动直连”仍可能接受对端要求的 P2P，不保证强制中转；“仅直连”不启用延迟优先。打洞和 UPnP 开关允许尝试，不保证成功。

## 邀请与配置迁移

点击“邀请朋友”直接复制；复制失败可手动复制。运行中分享实际运行参数，存在待应用修改时需重连后重新分享；已停止时分享已保存参数，状态未知或切换中暂不可分享。部分复杂认证配置无法简化为邀请，会明确提示。

接收方在加入对话框粘贴，核对并修改填入的内容，再手动添加、连接。邀请不会自动保存或连接，也不会带入发送方的网卡、IP 或高级参数。邀请包含加入凭据，可以继续转发；编码不提供加密，也不支持单份撤销、限次或过期。

网络配置页可导入官方 TOML，预览后创建独立、默认手动连接的记录；每条记录可导出已保存配置。未展示字段尽量保留；暂不支持的内容可保存、导出，但会阻止连接。导出包含凭据及本机参数，用于迁移；不保证保留注释和排版。

## 设备与流量

设备列表展示当前远端节点；点击名称展开协议、下一跳和核心版本，点击图标设置本机显示偏好。直连、中转及质量来自核心实际信息；未知值显示 `—`。核心运行、发现节点和目标应用可访问是不同事实。

流量统计当前网络在本机的隧道收发字节，包含核心通信和转发，不是整机互联网用量或文件净大小。切换查看对象不清空累计；重启目标网络建立新会话，累计归零，其他网络不受影响。停止后保留最后快照，不保存跨会话流量历史。

数据过期时保留设备和累计，速率与质量显示未知，曲线留下缺口。查询失败不等于主动断开；统计为采样结果，不用于计费。

## 后台、启动与恢复

默认关闭窗口后隐藏到托盘并保持连接，首次关闭会说明；设置中可改为退出。托盘可打开窗口或明确退出，重复启动只唤起已有窗口。有运行或待恢复网络时，退出需确认并等待核心清理。

登录启动默认关闭，启用后当前用户登录时启动并进入托盘；它与逐网络自动连接独立，不支持登录前组网。取消启动队列中的 UAC 会停止该次队列。免安装版开启登录启动后应保持路径固定，移动后重新设置。

自动恢复只针对本次客户端会话中原本运行的网络，使用断线前参数，保留待应用修改。临时没有节点由 EasyTier 自行重试；恢复需要提权时提示手动重连，不在后台弹 UAC。主动断开会取消恢复；重新开启恢复不会启动已断开的网络。

## 软件更新

默认启动约 10 秒后按需检查新版本，运行期间每 24 小时检查一次；上次尝试时间会保存，反复启动不会频繁请求。关于页可手动检查，短时间内复用成功结果，也可关闭自动检查或选择接收预发布版本。正式版默认仅接收正式版，预发布版默认也接收预发布；仅提示比当前版本更高的完整发布。

安装版发现更新后，点击“下载并更新”下载签名 NSIS，支持进度、取消和失败重试，下载期间保持网络连接。安装前有运行网络会确认断开，清理成功后才安装并重启；配置保留，连接按原有自动连接设置恢复。免安装版仅提供 ZIP 下载，完整解压到新目录后手动切换。

首次使用更新功能需手动安装包含更新器的版本。检查失败会保留已知更新并提示错误；服务限流时显示可重试时间，也可从 Releases 手动下载。rc1 使用旧版检查入口，升级到后续版本后使用静态更新索引。

## 数据与问题排查

桌面配置位于系统用户配置目录，安装版和免安装版共用该目录。配置、备份和异常原件可能含明文凭据，界面遮罩不代表磁盘加密。损坏文件不会被自动覆盖，可明确恢复上一版备份；浏览器网络数据仅保存在内存中，刷新恢复演示数据。

| 问题                       | 处理                                                           |
| -------------------------- | -------------------------------------------------------------- |
| 网卡名、地址或网络身份冲突 | 先检查其他运行网络及系统网卡，修改目标配置后再连接             |
| 核心运行但无法访问应用     | 分别检查节点发现、虚拟地址和目标服务，不能仅凭运行标记判断成功 |
| 数据暂未更新或配置读取失败 | 查看错误、刷新或重新加载；保留原配置，必要时使用备份恢复       |

设置中的诊断可查看配置、核心、网卡及近期错误，打开日志目录并导出脱敏 JSON；导出不会自动上传。反馈问题时提供应用／核心版本、复现步骤和脱敏诊断，不发送原始配置、密钥或邀请。关于页可复制版本信息。

安装、升级会中断连接并先清理已有实例；卸载默认保留配置，明确勾选才删除应用数据。当前不提供服务器部署、移动端、系统服务模式、任意核心切换或主动带宽测速。
