# 邀请与快速加入

阶段 6 提供 ClearTier 客户端之间的复制、粘贴邀请。邀请与阶段 5 的官方 TOML 兼容是独立功能；这里不生成或分享 TOML 文件。

## 使用流程

仪表盘「邀请朋友」点击后直接复制邀请，不打开选择框。底部提示说明邀请包含加入凭据，可以转发；复制失败时打开可选中、手动复制的文本框，不显示复制成功。

参数来源规则：

| 状态 | 邀请来源 |
| --- | --- |
| 核心运行且已知运行参数 | 当前运行参数；没有远端节点也可生成 |
| 已停止，或失败且已释放运行配置 | 已保存参数 |
| 正在启动／停止、状态未知、缺少运行参数或仍占用失败实例 | 不生成，提示等待切换或刷新状态 |

存在待应用修改时，仍复制当前运行参数，同时提示重连后重新分享。复制不会重连、应用修改或修改本机配置。异步提取期间参数发生变化时拒绝复制，避免使用迟到结果。

「加入网络」的现有对话框顶部提供紧凑的可选邀请输入。粘贴后在本地解析并填入网络名称、密钥、服务器及建议本地名称；用户自己填写的本地名称保留。成功后原文收起为「已填入」及「更换邀请」，焦点移到本地名称；邀请区域保留支持文本的空间，状态切换不改变后续字段位置。之后仍使用原有添加操作，不因粘贴而自动保存或连接，新记录的自动连接默认为关闭。

节点名称、实例 UUID、网卡名称、虚拟地址、图标及高级参数使用接收方自己的值或默认值。邀请是一次填入动作，之后以表单为准；只有主动选择「更换邀请」并成功解析新内容，才再次填入。更换操作及解析失败均不清空已有字段；失败只在邀请区说明未识别原因及未修改下方内容，用户可继续填写并添加，提交只校验实际网络字段。

保存失败保留已填入状态或未识别文本及表单，允许重试。相同名称和密钥触发已有重复网络确认，可打开已有网络或明确另存一套；不覆盖已有服务器与配置。重复／放弃确认返回表单时，已填入状态或未识别文本仍保留，并恢复到相应的表单控件。后续手动连接沿用阶段 3 的核心错误、重试及同网络互斥规则。

## v1 格式

```text
cleartier:v1:<Base64url(UTF-8 JSON)>
```

JSON 只包含：

| 字段 | 含义 |
| --- | --- |
| `name` | 精确网络名称，保留首尾空白 |
| `secret` | 精确网络密钥，允许为空，保留空白与字符 |
| `servers` | 入口 URI 列表，至少一条，相同项去重 |
| `displayName` | 可选建议本地名称，接收方可修改 |

不包含 UUID、发送方节点名称、IP、TUN 名称、P2P、MTU、自动连接偏好或原始 TOML。不添加邀请编号、有效期或使用次数；编码不构成加密、签名或服务端授权。第一版不承诺单份邀请撤销、限次或强制过期。

编码使用无填充 Base64url，不注册操作系统协议，不依赖分享网站。允许从带文字、空白和常见标点的聊天内容中提取单份邀请；多份邀请、未知版本、未知字段、错误类型、无效 UTF-8、截断或非规范编码都明确拒绝。解析时不访问 URI 指向的网络。

输入上限 64 KiB 字符，邀请正文上限 32 KiB 字符；名称／密钥／显示名称分别限制为 512／4096／256 个 UTF-16 单元，最多 16 个入口，每项最多 2048 个字符。支持当前常见远端入口协议 TCP、UDP、WG、QUIC、WS、WSS、HTTP、HTTPS、TXT、SRV。拒绝缺少主机、无效端口、回环及未指定地址；私有网段地址保留支持，不推断其对朋友一定可达。

## 实现组织

- `features/invitations/invitation.ts` 集中处理 v1 编解码、输入校验、运行／已保存参数选择和表单填入规则。
- `share-invitation.ts` 隐藏异步提取、源配置快照、迟到结果检查和剪贴板结果，依赖读取参数与复制两个 Adapter，通过同一 Interface 测试。
- 桌面 `invitation_parameters` 委托 `cleartier-core::invitations`，从实际生效的 TOML 中提取最小信息。未知配置、额外凭据、安全模式、固定对端公钥或非默认加密算法等暂不能可靠简化时拒绝生成；不静默遗漏必需参数，不共享本机私钥。
- 原生剪贴板使用 Tauri clipboard-manager，只授予 `allow-write-text`，不读取或监听用户剪贴板。浏览器使用现有网页复制与手动复制兜底，预览普通演示网络可以完整操作邀请流程。
- 表单只接收白名单字段，原有持久化队列及运行控制 Interface 不变。邀请和密钥不进入日志、URL、诊断文本或另存的邀请历史；网络配置仍按已确认的明文存储规则保存凭据。

## 验证与 Windows 验收

本地测试覆盖编码往返、Unicode 和精确凭据、字段白名单、版本／长度／端点错误、运行及离线参数来源、异步参数变化、复制失败、接收方参数隔离，以及普通添加与持久化衔接。Rust 测试验证真实 TOML 提取和复杂认证配置拒绝。浏览器用模拟原生通信及测试自有的剪贴板数据覆盖端到端界面流程，不访问系统剪贴板或真实服务器。

Windows 新包待验收：

1. 连接一个测试网络，一键复制邀请，在另一台 ClearTier 粘贴，核对自动填入、不同 UUID／TUN 名称及默认手动连接；手动连接后验证两机通信。
2. 修改发送方名称／密钥并选择稍后应用，复制内容仍对应当前连接；重连后再次复制才反映新参数。
3. 未连接时可复制已保存配置；状态未知时先刷新，缺少或无效入口时提示处理。
4. 验证系统剪贴板复制、手动复制兜底、保存失败后重试、重复邀请打开已有网络及连接失败后的配置保留。
5. 在多个网络运行时分享其中一个，确认其他网络不被断开或重建。TOML 导入导出继续按阶段 5 独立验收。
